# BLINKIT-SALES-DASBOARD-
1.Overview

This is a comprehensive Power BI sales analytics dashboard for Blinkit, a grocery delivery platform. The dashboard provides detailed insights into sales performance, outlet operations, and product metrics across multiple dimensions.

2.Primary Table: BlinkIT Grocery Data

The dashboard analyzes 12 key dimensions and metrics:
Item Attributes:
  A.Item Type (product categories)
  B.Item Fat Content (product properties)
  C.Item Weight
  D.Item Visibility
  E.Item Identifier

3.Outlet Information:

 A. Outlet Identifier
 B. Outlet Type (store types)
 C. Outlet Location Type (urban/rural/tier)
 D. Outlet Establishment Year (temporal analysis)
 E. Outlet Size

4.Performance Metrics:

Sales (revenue metric)
Rating (customer satisfaction)
Visual Components

5.The dashboard includes 26 strategically positioned visualizations covering:

Sales Performance: Multiple views of revenue trends and comparisons
A. Product Analysis: Item type distributions, fat content analysis, visibility metrics
B. Outlet Analysis: Store performance by type, location, and establishment year
C. Customer Ratings: Rating distribution and satisfaction insights
D. Key Metrics Display: KPI cards and summary indicators
E. Images/Branding: Custom icons and background imagery for visual appeal
F. Design Features
G. Colorful, vibrant background wallpaper for visual engagement
H. Multiple KPI cards with sales metrics
I. Rating star indicators for visual representation
J. Professional theme (CY26SU05 theme applied)
K. Responsive layout with clear spatial organization

6.Use Cases

This dashboard is ideal for:

Sales managers tracking outlet performance
Regional analysis across different store types and locations
Product-level performance monitoring
Customer satisfaction tracking through ratings
Temporal analysis of store establishment impact on sales
